# 笔记模板

## 1. 核心决定

用普通模板满足原先“固定格式文档”的需求：模板只提供创建笔记时的共同起点，创建后不持续控制文档格式。

不建立必须保持统一字段和排版的固定文档类型系统。

## 2. 创建与使用

- 用户创建新笔记时可以选择模板，也可以从空白笔记开始。
- 模板可以包含初始标题结构、正文提示、列表和可选的明文属性，例如游戏名称、状态、评分等。
- 套用模板后生成普通笔记，不需要依赖原模板才能打开或编辑。
- 用户可以创建和修改自己的模板；内置模板只作为可选示例。

## 3. 创建后完全自由

- 用户可以增加、删除或修改字段、标题、段落和排版。
- 不强制必填字段，不因偏离模板阻止保存。
- 修改或删除模板，不影响已经创建的笔记。
- 由同一模板创建的文档可以逐渐形成不同结构，不要求相互保持一致。
- AI 不得因为笔记偏离模板就自动改回模板格式。
- 当前不引入模板版本向已有笔记传播、固定表单或按文档类型强制校验等机制。

## 4. 存储与 AI 边界

- 模板内容沿用知识库的公开、可读格式，Markdown 模板可以使用 YAML Front Matter 保存初始属性。
- 不依赖模板插件私有语法或可执行脚本才能生成、阅读和迁移笔记。
- 用户模板属于原始资料，应保存在 `raw/Areas/_templates/` 内，以便最小化备份也包含它们；这是 Areas 下的普通子目录，不形成第五种知识空间。
- 模板套用属于知识库本体的基础功能，不依赖 AI，并可在模板已保存在本机时离线使用。
- AI 知识管理员可以在用户明确要求时帮助创建模板或按模板生成笔记，写入继续遵循明确授权、版本记录和撤销规则。

## 5. 验收原则

- 从同一模板创建的两篇笔记拥有相同初始结构，但之后可以独立修改。
- 删除模板字段或改变笔记结构不会被自动恢复，也不会阻止保存。
- 修改、重命名或删除模板不会改变已创建的笔记。
- 关闭 AI 后仍可使用模板创建普通笔记。
- 模板与生成的笔记均可以使用公开格式读取和迁移。
