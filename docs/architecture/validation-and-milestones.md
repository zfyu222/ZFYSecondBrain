# 技术验证与开发里程碑

状态：设计计划，所有验证均未执行；没有业务实现或依赖安装。范围见 [Web 首版](../requirements/web-first-release.md)，方案见[整体架构](./technical-design.md)。

## 1. 先验证风险，再铺开功能

每项原型须留下测试用例、环境、实际结果和是否通过，不以库的演示页面代替验收。下面规模是初始测试夹具，不是已承诺的性能指标；最终阈值需在目标设备上记录。

| 验证 | 场景与通过条件 | 不通过时 |
| --- | --- | --- |
| V1 格式与编辑 | 中文输入法、连续输入/撤销；OFM 链接、媒体、Callout、Front Matter；OPML/YAML 保存重开；100/500 节点夹具的键盘、触屏、折叠、正文、语义线；修改一处不丢其他原文或属性 | 更换编辑/布局适配器，不改变原始格式；不把导图首版范围静默删掉 |
| V2 离线与同步 | 断网输入后刷新恢复；存储满时不显示已保存；两个标签页和两个浏览器同改、不同改、同名新建、删除对编辑、重试请求；基线缺失不覆盖；未同步导出可读取 | 停止扩展功能，先修复本地持久化和并发协议 |
| V3 路径事务与恢复 | md/opml/relations/assets 及入站引用整体移动；逐提交步骤注入进程终止/写入失败；外部编辑插入；离线旧路径上传；从完整/标准/最小备份恢复 | 未验证前不开放自动 Inbox 移动；仍保留该首版要求，不能以普通文件重命名替代验收 |
| V4 AI 权限与来源 | 管理员无原始目录挂载；普通问答不写入；提示注入不能获得工具权限；授权修改有历史；AI 旧快照被拒绝；排除 Archive 与派生穿透；模型断开不影响知识库 | 调整或替换 Agent 适配器，不放宽知识库权限边界 |
| V5 原生复用可行性 | 同一前端包在 Windows/安卓壳打开与离线保存；安卓原生轻量窗口在主 WebView 未运行时保存，之后 App 可见且进入同一同步队列 | 评估替代壳或桥接；不重写整个前端，也不冒称控件已经实现 |
| V6 NAS 与安全访问 | 核实型号和 CPU/DSM；容器持久目录、重启、权限、HTTPS、时区；暂停管理员不影响知识库；SQLite 驱动和中文索引可运行 | 修正部署方式；不为通过演示而开放匿名公网入口 |

V1–V3 优先；V4 在正式接入 AI 前完成；V5 在共享核心定型前做最小桥接验证，但不交付完整安卓应用；V6 在实际 NAS 验收前完成。没有安卓设备/SDK或 NAS 信息时记录“未验证”，不得伪造通过，也不阻止可独立进行的格式和 Web 验证。

测试框架拟采用 [Vitest](https://vitest.dev/guide/) 与 [Playwright](https://playwright.dev/docs/intro)；移动模拟用于布局回归，实际输入法、WebView、系统控件和持久化仍需真机测试。

## 2. 格式契约先行的小清单

在 V1/V2 前写明 schema 与夹具，避免边写 UI 边发明不可迁移状态：

- Markdown 原文保留、受支持 OFM 子集、HTML/附件安全规则；仅导图笔记元数据、双视图开关的明文归属。
- OPML 正文属性、XML 转义、未知属性处理、节点同名/改名/移动消歧；YAML 关系方向与版本。
- 路径大小写、Unicode、保留文件名及锚点规则；无标题片段不能依赖不透明 block ID。
- 设备共同基线与双视图共同基线分离；可读移动链、删除记录、幂等提交和冲突项格式。
- 文件事务日志、历史/回收站清单、索引可删除重建；未同步本地数据不属于可随意删除的索引。
- API/工具的授权上下文、来源版本和确定性错误类型；AI 只能提交可校验的变更计划。

这些是接下来的工程细节，由实现方决定并测试；若必须放宽既定产品原则，单独提出，不冒充普通字段调整。

## 3. 开发里程碑

里程碑是先后依赖，不是发布日期。除技术验证外，每一阶段都要有可演示、可测试的完整操作流程。

| 阶段 | 产物 | 完成标准 |
| --- | --- | --- |
| M0 设计与风险验证 | 本轮范围/架构文档，随后格式/API 契约与 V1–V3 原型 | 写清数据与边界；原型有实际记录；本轮仅完成文档部分 |
| M1 最小笔记闭环 | Web 登录、Inbox 新建、Markdown 编辑、本地保存、NAS 文件落盘与读取 | 新建 → 保存本机 → 同步 → 另一浏览器打开；基础版本检查、失败不丢稿；不是完整首版 |
| M2 组织与安全底座 | 文件夹、标签、软链接、搜索、最近/收藏、引用维护、历史、回收站、模板/附件、外部编辑检测 | 断网/并发/移动/删除/恢复流程通过，V2/V3 全量回归 |
| M3 思维导图与双视图数据 | 导图编辑、语义线、引用、开放格式，两个视图各自可编辑及待同步状态 | 无 AI 也能保存/重建导图；保留两类基线；V1 与同步测试通过 |
| M4 管理员与按需语义同步 | 可替换管理员、个人知识检索问答、受托编辑、手动生成与同步 | 引用原文、任务级权限、冲突二选一、写回历史；V4 通过；关闭 AI 仍可用 |
| M5 每日整理与 Web 首版验收 | 摘要、Inbox 归类、双视图定时处理、应用内通知、NAS 部署和备份说明 | 默认本机 3 点、授权/失败/重跑可靠；V6 通过；首版端到端清单全部通过 |
| 后续 | 分层知识图谱/GraphRAG、Windows/安卓安装版、安卓控件、系统推送 | 顺序在 Web 使用反馈后确定；不把它们降级为可选想法 |

M3 中先完成基础数据编辑；M4 才加入 AI 语义转换。这样不把“有两个编辑器”错误地等同于“已经完成双视图同步”。

## 4. 仍需少量产品确认或外部输入

- 极短文本摘要：严格 1/10 下不足十字正文无法产生非空摘要。建议短文本直接作为列表预览，不伪称生成了符合比例的摘要；这是拟议例外，摘要实现前需用户确认，当前不修改既有规则。
- NAS 型号、DSM、内存、CPU 和访问方式：在部署原型前提供。
- 模型服务与费用上限：在 AI 接入前提供，不预设购买服务或本机部署大模型。
- 目标设备/浏览器与原生平台最低版本：在编辑器及原生桥接测试时核实。

回收站与历史暂不自动清理；未来空间策略如果要引入不可恢复删除，须单独确认。现在无需为普通字段、库版本或目录命名逐项召开需求讨论。
