版本测试还发现：仅增加 Dexie 数据库版本不能保证旧客户端无法重新打开，因此没有把它当作写入隔离方案。现在的生产 Worker 不再跳过等待期或接管未受控页面；根导航固定使用同构建的不可变 HTML，不从可变的 `/` 混入新代码。更新提示要求先保存/导出，再关闭全部原型标签页重开；不刷新正在编辑的页面，不删除 IndexedDB。

这只是生产界面升级策略的模拟生命周期与构建产物验证，不是完整客户端版本隔离。首次未受控页面、开发模式、旧版 Worker 向本版迁移、浏览器强制更新/缓存淘汰、后端协议及真实新旧标签页仍待验收。升级前须关闭旧版标签页，不能宣称所有版本可并存写入。

外部进程可以在版本检测之后写入文件，当前没有操作系统级排他锁。因此不得直接让外部编辑器和原型服务并发管理真实原文。异常注入测试仅证明已列出的回滚分支，不证明物理断电一致性。
